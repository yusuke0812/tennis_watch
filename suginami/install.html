杉並テニス空きボタン

杉並区さざんかねっとの「施設別空き状況」画面で押すと、土日祝の「空き」「一部空き」を一覧にします。 前回押したときになかった空きには NEW が付きます。

🎾 杉並テニス空き

登録のしかた（Chrome / Edge）

  1. ブックマークバーを表示します（Ctrl + Shift + B）。
  2. 上の緑のボタン「🎾 杉並テニス空き」を、ブックマークバーへドラッグして離します。

使いかた

  1. さざんかねっとで「利用目的から探す → スポーツ施設 → その他屋外スポーツ → テニス（硬式）→ 検索 → 4施設にチェック → 次へ進む」と進みます。
  2. 表示期間を「1ヶ月」にして表示すると、先までまとめて確認できます。
  3. 表が出たら、ブックマークバーの「🎾 杉並テニス空き」を押します。

このボタンは画面に表示済みの内容を読むだけで、サイトへの通信や操作はしません。前回の結果はこのブラウザの中にだけ保存されます。
